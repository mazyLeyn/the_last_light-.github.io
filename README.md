# 🕯️ The Last Light

**The Last Light**, Doğrudan tarayıcı üzerinden oynanabilen minimalist bir 2D hayatta kalma / aksiyon oyunudur.

🎮 **Oyna:** [The Last Light](https://mazyleyn.github.io/the_last_light-.github.io/)

---

## 🕹️ Nasıl Oynanır?

- **Kontroller:** 
  - `W, A, S, D` veya `Yön Tuşları`: Karakteri hareket ettirir.
- **Amaç:** Karanlıkta hayatta kalmak, etraftan kaynak toplamak ve "son ışığı" korumak.
